CraftDeck 启动器 · 使用说明
============================

【桌面版】如果你下载的是 CraftDeck-3.6.1-win64-full.zip：
    1. 完整解压到一个文件夹；
    2. 双击 CraftDeck.exe 即可，无需安装 Node.js；
    3. 若双击无反应，先运行「启动（兼容模式）.bat」；仍不行则运行「浏览器模式.bat」。
    桌面版与浏览器版共用数据目录 %APPDATA%\CraftDeck。

【浏览器版】如果你下载的是 CraftDeck-3.6.1-web.zip：
1. 不要直接在压缩包里双击运行！请先把压缩包完整解压到一个文件夹
   （例如 D:\CraftDeck）。
2. 进入解压后的文件夹，双击「启动 CraftDeck.bat」。
3. 会弹出一个黑色命令行窗口，几秒后自动打开浏览器：
       http://127.0.0.1:25555
   如果浏览器没有自动打开，请手动在浏览器里输入上面的地址。
4. 保持黑色窗口开启；关闭窗口 = 关闭启动器。

二、常见问题
- 窗口一闪而过 / 提示 "Node.js not found"：
    说明电脑没有安装 Node.js。请到 https://nodejs.org/ 下载 LTS 版本安装，
    安装完成后重新双击「启动 CraftDeck.bat」。
- 窗口里出现 "CraftDeck 启动器已就绪" 但浏览器没反应：
    手动打开浏览器访问 http://127.0.0.1:25555 。
- 端口被占用：
    启动器会自动改用 25556、25557……，以窗口里显示的「本地地址」为准。
- 出现错误信息：
    在解压后的文件夹地址栏输入 cmd 并回车，执行：
        node server\server.mjs --port=25555
    把窗口里的错误信息发给作者。

三、数据位置
游戏、模组、存档、日志都保存在：%APPDATA%\CraftDeck
（在文件资源管理器地址栏输入 %APPDATA%\CraftDeck 可直接打开）

四、新功能入口
- 皮肤：左侧「皮肤」，上传/下载/按正版 ID 获取，支持安装皮肤补丁。
- 日志：左侧「日志」，启动器日志与游戏日志。
- 实例页「内容」：版本/模组/光影/账户一站式管理。
- 版本下载：点击 1.21 等大版本卡片 -> 弹出小版本；支持快照 / Beta / Alpha。
- 陶瓦联机：左侧「陶瓦联机」，首次使用会下载组件，创建/加入房间。
- 百宝箱：设置页底部，内存优化、清理缓存、文件校验、网络与端口诊断。
- 多线程下载：设置 -> 下载与网络 -> 下载线程数（默认 4）。

完整功能说明见 README.md。
